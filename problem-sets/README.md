# Individual Problem Sets

These five individual problem sets account for 15% of the course grade (3%
each). They are short concept, interpretation, calculation, and decision checks;
they are separate from the six applied challenges.

| Problem set | Focus |
|---|---|
| [Problem Set 01](problem-set-01/) | Framing, baselines, regression evidence, and leakage |
| [Problem Set 02](problem-set-02/) | Classification decisions, thresholds, and regularization |
| [Problem Set 03](problem-set-03/) | Trees, ensembles, and honest model selection |
| [Problem Set 04](problem-set-04/) | Segmentation, PCA, and neural-network evidence |
| [Problem Set 05](problem-set-05/) | Causality, fairness, and production monitoring |

Submit responses through the corresponding Blackboard assignment. Blackboard
is the authoritative submission and grading record. Do not submit through
GitHub.

Each set is individual work and uses the course's Yellow AI-use policy. Include
the required disclosure in Blackboard.
