# Week 1 Customer Split Micro-Lab

[![Open in Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/lathrahul/modern-ai-ml-exercises/blob/main/shared/notebooks/customer_split_micro_lab.ipynb)

This 8–12 minute Week 1 activity compares a random row-level validation split with a customer-level split. It demonstrates why repeated entities on both sides of a split can make performance look more credible than it is.

Students should:

1. Predict which score will deteriorate.
2. Run the row-level split.
3. Run the customer-level split.
4. Preserve one sentence explaining which result supports a future-customer claim.

No file submission is required. The activity prepares students for the Week 1 participation card and later challenge validation decisions.
